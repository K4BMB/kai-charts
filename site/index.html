kai-charts

Gráficos SVG para dashboards de gestión. Un núcleo sin dependencias y dos renderers — Angular y React — con la misma API, el mismo CSS y los mismos tokens de tema. Licencia MIT.

Demo Angular Demo React GitHub

Instalación

Angular 20+

pnpm add kai-charts

import { KcBarChart } from 'kai-charts';
<kc-bar-chart [categories]="c" [series]="s" />

React 18+

pnpm add kai-charts-react

import { BarChart } from 'kai-charts-react';
import 'kai-charts-react/styles.css';
<BarChart categories={c} series={s} />

Núcleo (sin framework)

pnpm add kai-charts-core

import { computeBarLayout } from 'kai-charts-core';
// layouts, escalas, formato Intl, tokens

Qué trae

Tema por tokens CSS

--kc-color-1..8 y colores derivados de currentColor: los gráficos heredan el tema de la app (claro, oscuro, marca) sin configuración.

Accesible

SVG etiquetado, barras enfocables con aria-label, tooltip por teclado y tabla espejo opcional para lectores de pantalla e impresión.

Responsive y ligero

Ancho fluido por ResizeObserver, alto fijo, SVG puro. Sin canvas, sin d3, sin dependencias.

Formato Intl

es-VE por defecto; cualquier locale, opciones de Intl.NumberFormat o un formateador propio.

Estados incluidos

Cargando (skeleton), sin datos, y ceros tratados como datos reales.

Solo presentación

Los componentes reciben datos ya mapeados (categories + series): encajan como adaptador UI en una arquitectura hexagonal.
